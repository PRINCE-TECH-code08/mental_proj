## Known limitations and failure modes
- **Data provenance NOT ESTABLISHED.** The Kaggle description says the data were "designed" as a "realistic representation" for educational/portfolio use; no collection protocol is documented. Results may reflect a generative process, not real students.
- Ages 18-24 only; two gender values only; 111 countries with 37.6% labelled 'Other'.
- Regression toward the mean: low true scores are over-predicted and high ones under-predicted (`reports/error_analysis.md`).
- **Sensitivity/instability:** perturbing inputs by plausible self-report noise (0.25 h) changes predictions with a 95th-percentile magnitude of 0.55 points (assumption-based, `results/sensitivity_extra.json`). Differences between repeated predictions smaller than this should not be interpreted.
- The model is not monotone in inputs (e.g. +1 h sleep raises the prediction in 74.5% of test rows and lowers it in the rest).
- `Country` has a non-trivial importance (permutation dMAE 0.060), i.e. the model uses a demographic proxy. Consider removing it in any real use.
- Stress_Level removal changes CV MAE by only 0.0025: the model does not rely on it, but it is conceptually close to the outcome.
